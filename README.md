# The Missing Backpack

A choose-your-own-adventure website about a college student
searching for a missing backpack containing a laptop and a
final project due that night.

Readers choose where to search and what to do after finding
the backpack. Their decisions lead to one of two endings:
submitting the project on time or missing the deadline.

## Play the Adventure

https://gabrielr1998.github.io/missing-backpack/

## Tools Used

- HTML for six connected story pages
- CSS for colors, fonts, spacing, and image sizes
- Sublime Text for editing the code
- GitHub Pages for publishing the website
